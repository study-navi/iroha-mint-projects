# イロハミント 制作管理

ホームページ制作案件の進捗、公開予定日、確認用URL・公開URL・資料URL、次の作業とメモを管理するアプリ。

## GitHub Pages

公開元は `main` ブランチの `/(root)`。ビルドは不要。変更はPRで確認し、mainにマージして反映する。GitHub Pagesにはアプリのコードのみが掲載され、案件データは利用中のブラウザのIndexedDBに保存される。案件を別端末に移すときは、画面上部の「バックアップ」でJSONを保存して読み込む。既存の同一案件は読み込み時に上書きしない。顧客情報やバックアップファイルはリポジトリにコミットしない。

## 開発と動作確認

```sh
python3 -m http.server 8000
```

http://localhost:8000/ を開く。登録、編集、再読み込み後の表示、検索、URLリンク、CSV出力、JSONバックアップと読み込みを確認する。ファイルを直接開く方式はESモジュールとIndexedDBに対応しない。

- `index.html` は画面構成
- `style.css` はスタイル
- `app.js` は一覧、入力フォーム、検索、エクスポート
- `model.js` は制作段階、プラン、入力設定
- `storage.js` はIndexedDBとバックアップ
